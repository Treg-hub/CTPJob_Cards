# Pressroom — Job card quality (operator pack)

**In-app only · CTP confidential · Do not photograph, copy, or share outside Job Cards**

Good job cards drive faster fixes and better preventive maintenance. Blank novels are not required — **clear structure** is.

---

## Always fill

| Field | Meaning |
|-------|---------|
| **Machine** | Equipment: **Wifag / Badenia / Aurora** (not the folder name alone) |
| **Location** | Where on that press (e.g. Unit 5, Folder 5/5, Turner bar 4) |
| **Part** | What failed when you know it (gate, piston, gauge, pipe) |
| **Description** | What is wrong / what you saw / when it happens |
| **Type** | Mechanical / Electrical / … as you understand it |

## Optional

| Field | Use when |
|-------|----------|
| **Comments** | Extra operator context only if useful |
| **Notes** | Technician findings |
| **Corrective action** | What actually fixed it (**required when closed**) |

## Examples (good)

- “Badenia · 5/5 Folder · Safety gate — gate does not hold closed; magnetic switch suspect; production running with temporary hold — **unsafe**.”  
- “Aurora · Folder · Turner bar 4 — no air; hiss at pipe joint; web unstable.”  
- “Aurora · Infeed draw rollers — do not engage auto after stop; web slack / break risk.”

## Examples (weak)

- “Broken”  
- “Folder problem”  
- “Same as yesterday” with no location  

## Safety-related cards

If guards, gates, interlocks, or emergency devices are involved: say so in the description and escalate — do not normalise bypasses.

## After the fix

Technicians: leave a **corrective action** others can search later (“replaced piston seals unit 5”, “renewed 45 mm air pipe TB4”). That is what preventive maintenance reviews use.
